# Shah Fashion - Premium Sarees

Welcome to the Shah Fashion project! This is an e-commerce web application for premium handwoven sarees.

## Live Demo

**Frontend is currently live at:** [https://shah-fashion.vercel.app](https://shah-fashion.vercel.app)

## Project Structure

- `frontend/`: Contains the React/Vite frontend application.
- `backend/`: Contains the Express.js backend API (Deployment Pending).
- `shared/`: Shared resources.

## Deployment Status

- **Frontend:** Deployed on Vercel.
- **Backend:** To be deployed on Render.
